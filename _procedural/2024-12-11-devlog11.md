This week, work was done to gamify the project. The first step in doing this was adding a controllable player, this was done using Unity's CharacterController class (Unity n.d). Once the character controller was implemented, free assets, such as walls, a player model, and collectables, were used to populate the game (Kenney 2024). A function to collect a coin was made.

<img src="/assets/images/coin-collect-code.PNG" style="display: block; margin: 0 auto" />

Following this, code from a previous project was utilised to spawn coins procedurally across the map (Zoltikrys 2024).
