This week, the focus was on introducing gamification elements to the project, beginning with the implementation of a controllable player character. This was achieved using Unity's CharacterController class (Unity n.d.), which provided a solid foundation for player movement and interaction within the game world.

Once the character controller was in place, the game world was populated with free assets, including walls, a player model, and collectibles, sourced from Kenney (2024). These assets brought the environment to life and added visual interest to the scene. To further enhance interactivity, a coin collection system was developed, allowing the player to collect coins scattered across the map.

To automate the placement of coins, procedural spawning was introduced. This was achieved by repurposing code from a previous project (Zoltikrys 2024), enabling coins to be distributed dynamically throughout the environment. This addition created a more engaging and exploratory gameplay experience.

Finally, Unity's Cinemachine package (Unity n.d.) was utilized to integrate a third-person camera.
